# ANO-007 — Les jours avec événement ne sont plus signalés en mode contraste élevé

| Champ | Valeur |
|---|---|
| **ID** | ANO-007 |
| **Type** | IHM (accessibilité) |
| **Sévérité** | Majeur |
| **Module** | `/planning` — calendrier mensuel |
| **Environnement** | Firefox 160.0.1, Linux, commit `a0d25ca`, couleurs forcées (blanc sur noir) |
| **Test associé** | TSP55-02 (exigence SP55) ; lié à ANO-004 et TSP58 |
| **Pré-requis** | Connecté, base initialisée avec `python seed.py` ; Firefox → Paramètres → Couleurs → « Remplacer les couleurs spécifiées par la page : Toujours » |

## Étapes de reproduction
1. Activer les couleurs forcées dans Firefox (voir pré-requis).
2. Ouvrir http://localhost:5173/planning sur un mois contenant des événements.
3. Observer les cases des jours.

## Résultat attendu
Les jours qui ont un événement restent repérables en mode contraste élevé.

## Résultat obtenu
Les pastilles d'événement **disparaissent complètement** : rien ne distingue un jour avec
événement d'un jour vide. La pastille est un `<span>` vide dont seule la couleur de fond
(`bg-orange-400`) est visible ; le mode contraste élevé supprime les couleurs de fond.

## Preuve
Constat du testeur le 2026-11-24 (Firefox 160.0.1, couleurs forcées « Toujours ») : aucune pastille visible sur les jours avec événement.
Code : `frontend/src/views/PlanningView.vue` ligne 99 (pastille = `<span>` vide, couleur portée uniquement par `background-color`).

## Correction suggérée
Ajouter un indicateur qui ne dépend pas de la couleur de fond : bordure
(`forced-colors:border`), symbole ou texte (« • 2 événements » visible ou
`aria-label`), ou la règle CSS `@media (forced-colors: active)` avec `background: CanvasText`.
