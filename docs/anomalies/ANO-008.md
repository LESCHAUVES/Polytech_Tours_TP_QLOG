# ANO-008 — L'onglet actif de l'administration n'est plus identifiable en mode contraste élevé

| Champ | Valeur |
|---|---|
| **ID** | ANO-008 |
| **Type** | IHM (accessibilité) |
| **Sévérité** | Mineur |
| **Module** | `/admin` — onglets Joueurs, Équipes, Poules, Comptes |
| **Environnement** | Firefox 160.0.1, Linux, commit `a0d25ca`, couleurs forcées (blanc sur noir) |
| **Test associé** | TSP55-03 (exigence SP55) ; lié à TSP47 (sémantique des onglets) |
| **Pré-requis** | Connecté en administrateur ; Firefox → Paramètres → Couleurs → « Remplacer les couleurs spécifiées par la page : Toujours » |

## Étapes de reproduction
1. Activer les couleurs forcées dans Firefox (voir pré-requis).
2. Ouvrir http://localhost:5173/admin.
3. Cliquer successivement sur les onglets Joueurs, Équipes, Poules, Comptes.

## Résultat attendu
L'onglet actif reste visuellement distinct des autres.

## Résultat obtenu
**Aucun onglet n'est souligné**, y compris l'onglet actif : les quatre onglets sont identiques
et rien n'indique celui qui est sélectionné. L'onglet actif n'est signalé que par la couleur de
son soulignement (`border-padel-600`) et de son texte, couleurs remplacées par le navigateur.
Les onglets n'ont pas non plus d'attribut `aria-selected` (voir TSP47).

## Preuve
Constat du testeur le 2026-11-24 (Firefox 160.0.1, couleurs forcées « Toujours ») : aucun des quatre onglets n'est souligné.
Code : `frontend/src/views/AdminView.vue` lignes 132-138 (onglet actif signalé uniquement par `border-padel-600 text-padel-600`).

## Correction suggérée
Signaler l'onglet actif autrement que par la couleur : texte en gras, soulignement épais
toujours présent, `role="tab"` + `aria-selected="true"`, et règle
`@media (forced-colors: active)` qui force une bordure `Highlight` sur l'onglet actif.
