# ANO-011 — Les jours du calendrier n'annoncent ni leur date complète ni leurs événements

| Champ | Valeur |
|---|---|
| **ID** | ANO-011 |
| **Type** | IHM (accessibilité) |
| **Sévérité** | Majeur |
| **Module** | `/planning` — calendrier mensuel |
| **Environnement** | Analyse du code, commit `a0d25ca` — à confirmer avec un lecteur d'écran (NVDA / Orca) |
| **Test associé** | TSP59-03 (exigence SP59) ; TSP46 (Accessibilite_Calendrier) |
| **Pré-requis** | Connecté, base initialisée avec `python seed.py` ; lecteur d'écran actif |

## Étapes de reproduction
1. Se connecter et ouvrir http://localhost:5173/planning.
2. Parcourir les jours du calendrier avec `Tab` en écoutant le lecteur d'écran.

## Résultat attendu
Chaque jour annonce sa date complète et la présence d'événements, par exemple
« 15 décembre 2026, 2 événements, bouton » ; le jour sélectionné est annoncé comme tel.

## Résultat obtenu
Chaque jour est un `<button>` dont le seul contenu est le **numéro du jour** (« 15, bouton »).
La pastille d'événement est un `<span>` vide sans texte ni `aria-label` : un utilisateur aveugle
ne sait ni de quel mois il s'agit en parcourant les jours, ni quels jours ont un événement. Le
jour sélectionné n'a pas d'`aria-pressed` / `aria-current`.

## Preuve
Analyse du code : `frontend/src/views/PlanningView.vue` lignes 84 à 102.

## Correction suggérée
`:aria-label="`${day.toLocaleDateString('fr-FR', { dateStyle: 'full' })}${eventsByDate[ymd(day)] ? ', événements' : ''}`"`
et `:aria-pressed="ymd(day) === selectedDate"` sur chaque bouton de jour.
