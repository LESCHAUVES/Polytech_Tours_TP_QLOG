# ANO-004 — Pastille « jour avec événement » du calendrier insuffisamment contrastée

| Champ | Valeur |
|---|---|
| **ID** | ANO-004 |
| **Type** | IHM (accessibilité) |
| **Sévérité** | Majeur |
| **Module** | `/planning` — calendrier mensuel |
| **Environnement** | Firefox 160.0.1, Linux, commit `a0d25ca` |
| **Test associé** | TSP51-03 (exigence SP51 — WCAG 2.1 critère 1.4.11, niveau AA) ; lié à TSP58 (couleur seule) |
| **Pré-requis** | Connecté (joueur ou admin), base initialisée avec `python seed.py` (événements présents) |

## Étapes de reproduction
1. Se connecter et ouvrir http://localhost:5173/planning.
2. Se placer sur un mois contenant des événements.
3. Inspecter la pastille sous le numéro d'un jour avec événement (`data-cy="event-dot"`) → relever `background-color`.
4. Relever la couleur de fond de la case du jour, puis calculer le ratio.

## Résultat attendu
L'indicateur qui signale un jour avec événement a un contraste **≥ 3:1** avec le fond (WCAG 1.4.11).

## Résultat obtenu
Pastille `bg-orange-400` = `rgb(251, 146, 60)` (`#fb923c`) sur fond blanc : **2,26:1**.
La pastille ne mesure que **6 × 6 px** (`h-1.5 w-1.5`), ce qui la rend encore plus difficile à
repérer pour un malvoyant. Sur le jour sélectionné (fond `#1e40af`), le ratio est de 3,85:1.

## Preuve
Code : `frontend/src/views/PlanningView.vue` ligne 99 (`h-1.5 w-1.5 rounded-full bg-orange-400`). Ratio calculé selon la formule WCAG : `#fb923c` / `#ffffff` = **2,26:1**.

## Correction suggérée
`frontend/src/views/PlanningView.vue` : utiliser `bg-orange-600` (`#ea580c`, 3,56:1) ou plus
foncé, agrandir la pastille (`h-2 w-2`) et ajouter un indicateur non coloré (voir TSP58).
