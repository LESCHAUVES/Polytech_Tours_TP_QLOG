# ANO-009 — Titre de page identique partout et changement de page non annoncé

| Champ | Valeur |
|---|---|
| **ID** | ANO-009 |
| **Type** | IHM (accessibilité) |
| **Sévérité** | Mineur |
| **Module** | Toute l'application (`index.html`, `router/index.js`) |
| **Environnement** | Analyse du code, commit `a0d25ca` — à confirmer avec un lecteur d'écran (NVDA / Orca) |
| **Test associé** | TSP59-01 (exigence SP59) ; TSP48 (titre d'onglet propre à chaque page, WCAG 2.4.2) |
| **Pré-requis** | Aucun |

## Étapes de reproduction
1. Ouvrir http://localhost:5173/, puis naviguer vers `/planning`, `/matches`, `/results`.
2. Observer le titre de l'onglet du navigateur à chaque page.
3. Avec un lecteur d'écran actif, cliquer sur un lien du menu.

## Résultat attendu
Chaque page a un titre propre (« Planning — Corpo Padel »…) et l'arrivée sur une nouvelle page est
annoncée au lecteur d'écran (WCAG 2.4.2).

## Résultat obtenu
Le titre est **toujours « Corpo Padel »** (`index.html`), aucune vue ne le modifie et le routeur
n'a pas de hook `afterEach`. En navigation SPA, le focus n'est pas déplacé : le lecteur d'écran
n'annonce pas qu'une nouvelle page s'est affichée.

## Preuve
Analyse du code : `frontend/index.html` ligne 7, absence de `document.title` dans `src/`.

## Correction suggérée
Dans `router/index.js` : `meta: { title: 'Planning' }` sur chaque route et
`router.afterEach((to) => { document.title = \`${to.meta.title} — Corpo Padel\` })`, puis
déplacer le focus sur le `<h1>` de la page.
