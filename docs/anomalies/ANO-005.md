# ANO-005 — Un match annulé est affiché avec le statut « À venir »

| Champ | Valeur |
|---|---|
| **ID** | ANO-005 |
| **Type** | Fonctionnel |
| **Sévérité** | Majeur |
| **Module** | `/matches` — badge de statut des matchs |
| **Environnement** | Firefox 160.0.1, Linux, commit `a0d25ca` |
| **Test associé** | Constaté pendant TSP51-07 ; relève de TSP34 (Annulation_Suppression_Match, exigence SP34) et TSP31 (filtre par statut) |
| **Pré-requis** | Connecté en administrateur, au moins un match au statut A_VENIR |

## Étapes de reproduction
1. Se connecter en administrateur et ouvrir http://localhost:5173/matches.
2. Sur un match « À venir », cliquer sur **Annuler** et confirmer.
3. Observer le badge de statut du match.

## Résultat attendu
Le match passe au statut **ANNULE** (modèle de données §3.2 : A_VENIR / TERMINE / ANNULE) et le
badge affiche « Annulé », distinct visuellement de « À venir ».

## Résultat obtenu
Le badge affiche toujours **« À venir »**. Dans `MatchesView.vue`, la fonction `statusBadge`
ne traite que `TERMINE` ; tout autre statut, y compris `ANNULE`, tombe dans le cas par défaut
« À venir ». Les joueurs ne peuvent pas savoir qu'un match est annulé.

## Preuve
Code : `frontend/src/views/MatchesView.vue` lignes 65-68 (`statusBadge` sans cas `ANNULE`).

## Correction suggérée
Ajouter le cas `ANNULE` dans `statusBadge` (libellé « Annulé », par ex. `bg-gray-100 text-gray-700`).
